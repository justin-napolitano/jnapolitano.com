This repository hosts my personal website, built using Gatsby, a popular React-based static site generator. The site showcases my portfolio, blog, and contact information.

## Key Components:
- **Gatsby**: Framework for building static sites.
- **React**: UI library for building components.
- **GraphQL**: Used to manage and query site data.
- **Styled Components**: For styling React components.

## Getting Started:
To run the site locally, follow these steps:

1. Clone the repo:
    ```bash
    git clone https://github.com/justin-napolitano/jnapolitano.com.git
    ```
2. Navigate to the directory:
    ```bash
    cd jnapolitano.com
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Start the development server:
    ```bash
    npm run develop
    ```

## Gotchas:
Make sure you have Node.js (version 14 or higher) installed. If you encounter issues with paths, check your environment variables.
